# ADR-0031: 에이전트 지침은 최소로 두고 필요할 때 더한다

- 상태: Accepted (0013 확장)
- 날짜: 2026-10-03

## 맥락

[ADR-0013](./0013-docs-adr-and-agents.md) 은 문서를 둘로 나눴다. "왜"는 ADR 에, 규칙은 AGENTS.md 에
둔다. 그 뒤 AGENTS.md 는 작업마다 "밟은 지뢰"의 경위를 덧붙이며 778줄(72KB)까지 자랐다.
`CLAUDE.md` 가 이 파일을 import 하므로 매 세션 전부가 컨텍스트에 실린다.

이 지침은 예전 모델에 맞춰 쓴 것이다. 지금 모델은 코드·게이트·ADR 에서 많은 것을 스스로 읽어 낸다.
게다가 강조어와 서사가 많으면 정작 중요한 규칙이 묻힌다. 공식 지침도 메모리 파일을 짧게 두고, 코드에서
추론할 수 있는 것은 빼라고 권한다.

## 결정

AGENTS.md 에는 **코드·게이트·ADR 만 보고는 알 수 없는 것**만 둔다. 검증 명령, 불변식, 어긴 뒤에야
드러나는 비싼 함정 몇 개, 그리고 컨벤션이다. 나머지는 지운다.

규칙은 미리 쌓지 않는다. 같은 실수가 실제로 되풀이될 때 한 줄씩 더한다.

- 옛 지뢰 80개는 `docs/pitfalls.md` 로 원문 그대로 옮겼다. 매 세션 실리지는 않는다. 주제별로 묶었고,
  각 절 첫 줄이 그 절을 읽을 때를 적는다.
- 아키텍처 표, 스타일 구성, 상태 머신 목록은 지웠다. 접근성은 게이트가 못 보는 규칙만 남겼다. 각각 정본이 따로 있어서다.
  dependency-cruiser 설정, CSS 주석, `src/core/*.machine.ts` 가 그 정본이다.
- `kunya-design` 스킬도 같은 기준으로 줄였다. 역할 연기 문장, 브레이크포인트 표(근거는 CSS 주석에
  있다), 좁은 폭 점검 절차(스펙 파일이 말한다)를 걷었다.

## 근거

- 사실은 잃지 않는다. 지뢰의 경위는 `docs/pitfalls.md` 에, 결정은 ADR 에, 수치의 근거는 코드 주석에
  있다. 지운 것은 그 사실들의 사본뿐이다.
- 규칙이 적을수록 남은 규칙이 읽힌다. 80개의 지뢰 가운데 무엇이 데이터 손실로 이어지는지가 서사
  속에 묻혀 있었다.
- AGENTS.md 는 Codex 등 다른 도구도 읽는 공용 정본이다. 그래서 특정 도구의 기능에 기대지 않고
  평범한 마크다운 링크로 나눈다.

## 기각한 대안

- **압축해서 그대로 두기.** 실제로 해 보니 229줄이 남았다. 여전히 대부분이 코드에서 읽히는 내용이었다.
- **경로별 규칙(`.claude/rules`)으로 나누기.** Claude Code 전용이다. 공용 정본이 갈라진다.

## 결과

- (+) 매 세션 싣는 지침이 72KB 에서 약 6KB 로 준다.
- (−) 경위는 기본으로 읽히지 않는다. 에이전트가 함정을 다시 밟을 수 있다. 되풀이되면 그때
  AGENTS.md 에 한 줄을 더한다. 이 방식이 이 결정의 전제다.
